# Satellite Constellation Management System  
**Рефакторинг с применением порождающих паттернов GoF (Factory Method, Builder)**  

---

## 📌 Описание проекта

Проект представляет собой систему управления спутниковыми группировками, разработанную в рамках семинарского задания по дисциплине «Архитектура и паттерны проектирования».

Цель работы — выполнить рефакторинг существующего кода с применением порождающих паттернов GoF:

- **Factory Method** — для создания спутников различных типов  
- **Builder** — для пошаговой конфигурации системы энергоснабжения  

Проект реализован на **Java 24** с использованием **Gradle (Kotlin DSL)**.

---

## 🎯 Цели рефакторинга

В рамках работы было необходимо:

1. Вынести создание объектов спутников из сервисного слоя
2. Реализовать фабричный метод для создания разных типов спутников
3. Организовать пошаговую сборку EnergySystem через паттерн Builder
4. Отделить логику конструирования объектов от бизнес-логики
5. Упростить расширение семейства спутников

## 🧩 Используемые паттерны

### 1️⃣ Factory Method

**Назначение:**  
Инкапсулировать создание объектов спутников и исключить прямое использование конструкторов в сервисном слое.

**Интерфейс:**

```java
public interface SatelliteFactory {
    Satellite createSatellite(String name,
                              EnergySystem energy,
                              double parameter);
}
---

Конкретные фабрики:

CommunicationSatelliteFactory

ImagingSatelliteFactory

📌 Преимущество:
Добавление нового типа спутника требует только создания новой фабрики без изменения сервисной логики.

2️⃣ Builder (для EnergySystem)

Назначение:
Отделить процесс конфигурации системы энергоснабжения от её использования.

EnergySystem energy = EnergySystem.builder()
        .batteryLevel(0.85)
        .build();

📌 Преимущества:

Упрощает создание различных конфигураций

Централизует валидацию

Повышает читаемость кода

Исключает перегруженные конструкторы

🚀 Функциональные возможности

Система позволяет:

Создавать спутники связи и дистанционного зондирования Земли

Создавать спутниковые группировки

Добавлять спутники в группировку

Активировать все спутники группировки

Выполнять миссии

Отображать текущее состояние группировки

🔋 Логика работы спутников

Спутник может быть активирован только при достаточном уровне заряда:

batteryLevel > 0.2

Если энергии недостаточно:

🛑 <имя спутника>: не активен

При выполнении миссии происходит расход энергии.

▶ Запуск проекта
1. Требования

Java 24

Gradle 8+

gradle build

или

./gradlew build

java -cp build/classes/java/main com.example.space.Main

выполняется активация

запускается миссия

выводится состояние системы

Вывод строго синхронизирован с исходной версией проекта (включая эмодзи 🛑).
