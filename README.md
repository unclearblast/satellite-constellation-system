# satellite-constellation-system

## 📌 Описание
Консольная система управления спутниковой группировкой для аэрокосмической компании.
Проект реализован на Java с использованием принципов ООП и SOLID.

Система демонстрирует:
- абстракцию через базовый класс Satellite;
- наследование и полиморфизм;
- агрегацию спутников в группировку;
- расширяемую архитектуру.

## 🧩 Архитектура
- Satellite — абстрактный базовый класс
- ImagingSatellite — спутник ДЗЗ
- CommunicationSatellite — спутник связи
- SatelliteConstellation — группировка спутников
- Main — центр управления и тестирования системы

## 🛠 Используемые принципы
- Инкапсуляция
- Наследование
- Полиморфизм
- Абстракция
- SOLID (SRP, OCP, LSP)
